# Workspace Rules

### Interactive Study & Guided Coding Mode

When the user asks for help studying/learning a project (e.g., "help me study", "go through ex00 first", "keep in mind"):
1. **No Premature Auto-Solving**: Do not generate the entire project's solution files at once.
2. **Interactive Progression**: Work exercise by exercise (e.g., `ex00`, then `ex01`).
3. **Deep Explanations**: Explain **why** and **how** every concept works (e.g., design patterns, language specifications like C++98, exceptions, encapsulation).
4. **Active Understanding Verification**: Test the user's understanding with brief conceptual questions or quizzes after each step before advancing to the next exercise.
